# Referências do site — Empresa Bela

Este é o **espaço para depositar todo o material de referência** do site: como
você quer que ele se pareça, o que ele deve comunicar e qualquer material do
cliente. É a "porta de entrada" para entender o projeto.

> ⚠️ **Para o assistente de IA:** leia este README e o conteúdo relevante das
> subpastas **antes** de propor ou fazer qualquer alteração no site. As
> referências aqui têm prioridade sobre suposições.

---

## O que colocar em cada pasta

| Pasta          | O que vai aqui |
|----------------|----------------|
| `sites/`       | Screenshots de sites que servem de inspiração + `LINKS.md` com as URLs. |
| `imagens/`     | Mood board, logo/marca, paleta de cores, fotos de inspiração ou do cliente. |
| `documentos/`  | Briefings, propostas, PDFs, textos e qualquer material escrito do cliente. |

## Como adicionar uma referência

1. **Link de site** → adicione a URL em `sites/LINKS.md` (com uma linha dizendo
   o que observar nele).
2. **Imagem / print** → arraste o arquivo para `sites/` (se for print de site) ou
   `imagens/` (se for inspiração visual / marca).
3. **Documento** → coloque em `documentos/`.

Dê nomes descritivos aos arquivos (ex.: `home-habitatinvest.png`,
`briefing-cliente-v1.pdf`) — isso ajuda o assistente a entender sem abrir tudo.

## Dica

Não precisa organizar perfeitamente. O importante é **jogar o material aqui**;
o assistente consulta esta pasta antes de trabalhar no site.
